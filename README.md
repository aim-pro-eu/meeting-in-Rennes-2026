# meeting-in-Rennes-2026

GitHub Pages site with the practical information for the AIM-PRO plenary meeting in Rennes (20–21 October 2026), built from slides 2, 3, 5, 7 and 8 of the meeting deck. Styled after [aim-pro.eu](https://aim-pro.eu/).

- `index.html` – single page (programme, getting to Rennes, plane travel plan, IRISA venue, accommodation)
- `assets/style.css` – styles (Inter + slate/blue palette of the AIM-PRO website)
- `assets/img/` – AIM-PRO logos/hero (from aim-pro.eu) and images extracted from the slides

## Publish

Settings → Pages → *Deploy from a branch* → `main` / `/ (root)`.
